#### 进阶

* 将 [MVEL](https://www.github.com/mvel/mvel) 与 Easy Rules 结合使用。MVEL 支持是在 v3.1 中添加的，并通过该模块提供。此模块包含用于使用 MVEL 定义规则的 API。我们将在此处使用这些 API。目标是实现一个简单的商店应用程序，其要求如下：拒绝儿童购买酒精饮料。被视为成人的最低法定年龄为 18 岁。商店客户由 *Person* 类表示：`easy-rules-mvel`

  * 创建一个实体类

    ```java
    public class Person {
        private String name;
        private int age;
        private boolean adult;
        //getters and setters omitted
    }
    ```

  * 定义规则

    * 规则 1：应操作一个 a 实例，检查该人年龄是否大于 18 岁，并设置 adult 标志。`Person`

    * 规则 2：应操作实例，检查此人是否为成人，并拒绝儿童（即非成人）购买酒精。`Person`

    * 规则 1 应在规则 2 ***之前\***触发。我们将规则 1 优先级设置为 1，将规则 2 优先级设置为 2，以便 Easy Rules 引擎按此顺序触发它们。

    * 创建规则1

      ```java
      Rule ageRule = new MVELRule()
              .name("age rule")
              .description("Check if person's age is > 18 and marks the person as adult")
              .priority(1)
              .when("person.age > 18")
              .then("person.setAdult(true);");
      ```
