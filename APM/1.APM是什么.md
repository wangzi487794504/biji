#### APM是什么

* APM是应用性能监测

* 免入侵

  ![image-20251206142701988](./assets/image-20251206142701988.png)

* 需要重启，不重启那些bean需要重新实例化，相当于·热加载，容易出问题
*  java agent只是在目标jar包运行之前 jvm自动回调了自定义的修改字节码的相关类 生成了一个新的jar 实际运行的是新jar 所以java agent只是提供了一个恰当时机的回调 核心的功能还是要靠以asm javaassit等为代表的java字节码动态[![img](./assets/9f3ad0659e84c96a711b88dd33f4bc2e945045e0.png)修改框架](https://search.bilibili.com/all?from_source=webcommentline_search&keyword=修改框架&seid=13819688733654823659&from_avid=355175047&from_comid=161617773824)来实现
* Java Agent主要通过两个API来实现：
  * InstrumentationAPI：提供了在程序运行期间更改字节码的能力，可以用来动态地修改类的行为。通过InstrumentationAPI，JavaAgent可以在类被加载前，对其进行字节码的动态修改，可以插入自己的代码，用于收集统计数据、记录日志、跟踪调用堆栈等。
  * JavaVirtualMachineToolInterface（(JVMTI)：提供了在程序运行期间监视和控制JVM的能力。JVMTI可以用于监视内存使用情况、线程执行情况、调用堆栈信息、垃圾回收等信息，并可以通过JVMTI接口修改线程堆栈、执行跟踪等操作。
* JavaAgent通常以.jar文件的形式存在，并通过JVM参数-javaagent:agent.jar加载。在JVM启动时，JavaAgent的premain方法将
  被调用，并可以在此方法中进行一些初始化工作。如果需要在应用程序运行过程中动态地加载JavaAgent，可以使用
  VirtualMachine类的loadAgent方法，或者使用JMX远程调用来加载Java Agent。
