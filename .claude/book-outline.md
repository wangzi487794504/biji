  - 横向对比表：梯度流动、计算开销、零中心性、实际表现

### 第四章：全连接网络的局限——为什么要进化 ✅ 初稿完成
- 5.1 参数爆炸
  - 一张图片需要多少参数？
  - 计算：1000×1000 图片 → 10亿参数
  - 参数多 = 需要更多数据 = 更容易过拟合
- 5.2 没有空间感知能力
  - 全连接层把图像当成一维列表
  - 相邻像素和远处像素被同等对待
  - 丢失了像素之间的空间关系
- 5.3 没有平移不变性
  - 猫往左移一个像素 = 完全不同的输入向量
  - 网络需要**重新学习**每个位置的猫
  - 这极其低效
- 5.4 没有局部性先验
  - 图像中，相邻像素关系更密切
  - 全连接层没有利用这个先验知识
- 5.5 全连接网络的适用场景
  - 表格数据
  - 已经提取好的特征向量
  - 小型分类/回归任务

### 第六章：CNN 架构演进——从 LeNet 到 ResNet 📝 待写
- 7.1 LeNet-5（1998）：一切的开端
  - 结构：Conv → Pool → Conv → Pool → FC → FC
  - 手写数字识别的突破
- 7.2 AlexNet（2012）：深度学习革命的引爆点
  - ImageNet 上的惊人表现
  - 关键技术：ReLU、Dropout、GPU 训练
- 7.3 VGG（2014）：深度就是力量
  - 3×3 卷积堆叠的设计哲学
  - 简单但有效的架构
- 7.4 GoogLeNet / Inception（2014）：拓宽网络
  - Inception 模块：多尺度并行卷积
  - 1×1 卷积降维
- 7.5 ResNet（2015）：跳过连接的革命
  - 退化问题：更深反而更差？
  - 残差学习：F(x) + x 的魔力
  - 残差连接如何让梯度畅流无阻
  - ResNet-152：152层的壮举
- 7.6 DenseNet、MobileNet、EfficientNet
  - DenseNet：每一层都连接所有前层
  - MobileNet：深度可分离卷积，为移动端而生
  - EfficientNet：用 NAS 找到最优的深度/宽度/分辨率平衡
