# 🧠 AI科普·MD排版技能

## 📋 技能简介

撰写 AI 科普文章时，你是否常面临"内容专业但排版劝退"的问题？这个技能提供一套标准化的 Markdown 排版规范，让晦涩的算法、模型、数据概念变得一目了然，阅读体验接近杂志级排版。

## 🎯 适用场景

- 公众号/知乎 AI 科普图文
- 技术博客的入门讲解
- 产品文档中的 AI 模块说明
- 学习笔记、知识卡片分享

## ✨ 核心排版原则

| 要素 | 规则 | 视觉目的 |
|------|------|----------|
| 标题层级 | 只使用 H2～H4，H1 留给文章大标题 | 清晰的树状结构 |
| 重点标记 | 核心术语用 **粗体** + 反引号包裹，首次出现必标记 | 强化记忆锚点 |
| 列表分层 | 无序列表 `-` 用于并列，有序列表 `1.` 用于步骤；嵌套不超过2层 | 降低认知负荷 |
| 代码块 | 所有代码、prompt、指令一律用围栏代码块并标注语言 | 专业感与可复现性 |
| 引用块 | 用 `>` 突出重要定义、核心结论；可用 `> [!NOTE]` 创建彩色提示框 | 打造"高亮卡片" |
| 表格 | 对比概念、罗列参数时必用，表头加粗居中 | 密集信息结构化 |
| 图片 | 格式 `![描述](url)` 描述必填，建议配信息图/示意图 | 一图胜千言 |
| 装饰符号 | 恰当使用 emoji（🧠🤖📊💡⚠️✨）但不过度，每段最多2处 | 跳跃视觉，缓解阅读疲劳 |
| 分隔线 | 用 `---` 在章节间制造呼吸感 | 段落间留白 |
| 卡片式提示 | 使用 `> **💡 核心洞察**` 或 `> **⚠️ 常见误区**` 等模板 | 突出重点，适合扫读 |

## 🧩 排版模板结构

```markdown
## 🤖 章节标题（提问式更佳，如"什么是大模型？"）

### 📌 一句话概述
> 用1-2句大白话讲清这个概念的本质，零基础也能懂。

### 🔍 生活里的类比
- 🍎 把神经网络比作……
- 🧩 强化学习就像……

### ⚙️ 原理拆解（分步可视化）
1. **第一步：数据进入** – 描述
2. **第二步：模型处理** – 描述
3. **第三步：输出结果** – 描述

### 📊 关键对比（表格）
| 特性 | 传统程序 | AI 模型 |
|------|---------|--------|
| 规则 | 人工编写 | 从数据学习 |
| …    | …       | …      |

### 🧪 动手试一试
```python
# 简单的示例代码，让读者亲自感受
print("Hello AI")
```

> **💡 核心洞察**：这里放本段最重要的结论。

> **⚠️ 常见误区**：很多人以为…… 其实……
```

## 🎨 高级技巧：彩色提示框

如果你的发布平台支持（如 GitHub、Notion、部分静态博客），可以用这种写法创建彩色提示块：

```markdown
> [!NOTE]
> 这是一个普通的注释框，用于补充背景知识。

> [!TIP]
> 实用技巧：在写 prompt 时加上"请一步步思考"，效果更好。

> [!WARNING]
> 注意！微调模型可能需要大量算力，普通电脑难以完成。

> [!IMPORTANT]
> 关键伦理准则：使用 AI 生成内容时，必须遵守隐私与合规要求。
```

## 🔧 使用建议

1. **先搭骨架，再填血肉**：写之前按模板把标题和卡片框架拉好。
2. **一篇文章不超过 5 个重点色块**，避免视觉过载。
3. **代码块必须可运行或可演示**，空泛的伪代码不如给一个真实的 prompt。
4. **所有配图统一风格**，推荐使用扁平化、线条简约的信息图。
5. **发布前用预览工具检查**，确认表格对齐、代码高亮、emoji 显示正常。
