#### [最小栈](https://leetcode.cn/problems/min-stack/)

* 设计一个支持 `push` ，`pop` ，`top` 操作，并能在常数时间内检索到最小元素的栈。

  实现 `MinStack` 类:

  - `MinStack()` 初始化堆栈对象。
  
  - `void push(int val)` 将元素val推入堆栈。
  
  - `void pop()` 删除堆栈顶部的元素。
  
  - `int top()` 获取堆栈顶部的元素。
  
  - `int getMin()` 获取堆栈中的最小元素。
  
    ```java
    class MinStack {
        Deque<int[]> queue=new ArrayDeque<>();
        public MinStack() {
             queue.push(new int[]{0,Integer.MAX_VALUE});
        }
    
        public void push(int val) {
            queue.push(new int[]{val,Math.min(getMin(),val)});
        }
    
        public void pop() {
            queue.poll();
        }
    
        public int top() {
            return queue.peek()[0];
        }
    
        public int getMin() {
            //数组第二个元素存最小值
            return queue.peek()[1];
        }
    }
    ```
