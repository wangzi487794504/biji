#### 最长连续子序列

* 没有一个数-1在hashset上找不到，说明它是开头的数组

  ```java
      public int longestConsecutive(int[] nums) {
          HashSet<Integer> hashSet=new HashSet<>();
          for (int num : nums) {
              hashSet.add(num);
          }
          int currentCount=0;
          int maxLength=0;
          for (Integer temp : hashSet) {
              //如果一个数没有-1，说明它是一个起点
              if (!hashSet.contains(temp-1)){
                  int currentValue=temp;
                  currentCount=1;
                  while (hashSet.contains(currentValue+1)){
                      currentValue++;
                      currentCount++;
                  }
              }
              //更新最大长度
              maxLength=Math.max(currentCount, maxLength);
          }
          return maxLength;
      }
  ```
