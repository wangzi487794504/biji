#### [轮转数组](https://leetcode.cn/problems/rotate-array/)

* 给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

* 思路一：再用一个数组保存移动后的位置

* 思路二：三次反转

  ```java
  class Solution {
      public void rotate(int[] nums, int k) {
           //K对数组长度取余，快慢指针，快指针先走k个距离，然后两两交换位置
           k=k%nums.length;
           reverseList(nums,0,nums.length-1);
           reverseList(nums,0,k-1);
           reverseList(nums,k,nums.length-1);
      }
      public void reverseList(int[] nums,int start,int end){
          while(start<end){
              int temp=nums[start];
              nums[start]=nums[end];
              nums[end]=temp;
              start++;
              end--;
          }
      }
  }
  ```
