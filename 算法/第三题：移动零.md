#### 移动零

* 不相等的就交换

  ```java
  class Solution {
      public void moveZeroes(int[] nums) {
           //双指针
          int right= 0;
          for (int i = 0; i < nums.length; i++) {
              if (nums[i]!=0){
                 int temp=nums[i];
                 nums[i]=nums[right];
                 nums[right++]=temp;
              }
          }
      }
  }
  ```
