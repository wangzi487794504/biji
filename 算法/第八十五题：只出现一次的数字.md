#### [只出现一次的数字](https://leetcode.cn/problems/single-number/)

* 给你一个 **非空** 整数数组 `nums` ，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

  你必须设计并实现线性时间复杂度的算法来解决此问题，且该算法只使用常量额外空间。

  ```java
  class Solution {
      public int singleNumber(int[] nums) {
          //利用乘法
          int result=0 ;
          for (int num : nums) {
              result ^= num;
          }
          return result;
      }
  }
  ```

* 利用异或运算的特性

* 与运算：任何数和0做与运算，结果是0，任何数和其自身做与运算，结果是自身

* 或运算：任何数和0做或运算，结果是自身。任何数和其自身做或运算，结果是自身

* 异或运算：任何数和0做异或运算，结果是自身。任何数和其自身做异或运算，结果是0
