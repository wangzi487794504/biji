#### [二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

* 方法一：先序加队列

  ```java
  class Solution {
      
      public void flatten(TreeNode root) {
          //先序遍历
          //定义一个哨兵
          Queue<TreeNode> queue=new ArrayDeque<>();
          dan(root,queue);
          TreeNode temp=new TreeNode();
          TreeNode result=temp;
          for (TreeNode treeNode : queue) {
              temp.left=null;
              temp.right=treeNode;
              temp=temp.right;
          }
      }
      public void dan(TreeNode root,Queue<TreeNode> queue){
          if (root!=null){
              queue.add(root);
              dan(root.left,queue);
              dan(root.right,queue);
          }
      }
  }
  ```
