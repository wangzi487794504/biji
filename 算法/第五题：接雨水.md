#### 接雨水

* 解决方法一：使用前后缀最大值

  ```java
      public int trap(int[] height) {
          //构造两个数组，一个数组是前缀最大值
          //另外一个数组是后缀最大值
          int n= height.length;
          int[] preMax=new int[n];
          int[] afterMax=new int[n];
          int result=0;
          //初始化
          preMax[0]=height[0];
          afterMax[n-1]=height[n-1];
          for (int i = 1; i < height.length; i++) {
              preMax[i]= height[i]>preMax[i-1] ?height[i]:preMax[i-1];
          }
          for (int i = height.length - 2; i >= 0; i--) {
              afterMax[i]= height[i]>afterMax[i+1] ?height[i]:afterMax[i+1];
          }
          for (int i = 0; i < height.length; i++) {
              result+=Math.min(afterMax[i],preMax[i])-height[i];
          }
          return result;
      }
  ```
