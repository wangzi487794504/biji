#### [单词搜索](https://leetcode.cn/problems/word-search/)

* 给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

* 单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

  ```java
  class Solution {
      public boolean exist(char[][] board, String word) {
          // 思路：确定第一个位置，判断它的右边换个下面有没有第二个，有更新，没有接着往右移动，到头再往左移动
          char[] charArray = word.toCharArray();
          for (int i = 0; i < board.length; i++) {
              for (int j = 0; j < board[i].length; j++) {
                  if (dfs(board,i,j,charArray,0)){
                      return true;
                  }
              }
          }
          return false;
      }
      public boolean dfs(char[][] board,int i,int j,char[] charArray,int index){
          if (i<0 || i>= board.length || j<0 || j>=board[0].length || board[i][j]!=charArray[index]){
              return false;
          }
          if (index == charArray.length - 1) { // 匹配成功！
              return true;
          }
          //防止二次走
          char temp=board[i][j];
          board[i][j]='0';
          boolean dfs = dfs(board, i - 1, j,charArray,index+1);
          boolean dfs1 = dfs(board, i + 1, j,charArray,index+1);
          boolean dfs2 = dfs(board, i, j - 1,charArray,index+1);
          boolean dfs3 = dfs(board, i, j + 1,charArray,index+1);
          //还原防止失败的时候下一个用它
          board[i][j]=temp;
          return dfs|| dfs1 ||dfs2 || dfs3;
      }
  }
  ```
