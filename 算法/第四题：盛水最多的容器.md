#### 盛水最多的容器

* 思路：使用左右指针，谁小就移动谁，因为短的才是真正的高，每次比较保存最大值。

  ```java
  class Solution {
      public int maxArea(int[] height) {
          //思路就是
          int maxResult=0;
          int left=0;
          int right=height.length-1;
          while (left<right){
              if (height[left]<height[right]){
                  maxResult=Math.max(maxResult, (right-left)*height[left++]);
              }
              else {
                  maxResult=Math.max(maxResult, (right-left)*height[right--]);
              }
          }
          return maxResult;
      }
  }
  ```
