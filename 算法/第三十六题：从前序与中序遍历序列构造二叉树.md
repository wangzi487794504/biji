#### [从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

* 难点：

* ```
  //在处理前序数组的范围时，错误地将中序的索引当作前序的结束位置，导致范围错误。正确的做法应该是，
  // 前序的左子树范围应该根据左子树的大小来计算，而左子树的大小等于中序中找到的根的位置减去当前中序的起始位置。
  ```

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        return build(preorder, inorder, 0, preorder.length - 1, 0, inorder.length - 1);
    }

    private TreeNode build(int[] preorder, int[] inorder, int preStart, int preEnd, int inStart, int inEnd) {
        if (preStart > preEnd || inStart > inEnd) {
            return null;
        }

        int rootVal = preorder[preStart];
        TreeNode root = new TreeNode(rootVal);

        int inRootIndex = 0;
        for (int i = inStart; i <= inEnd; i++) {
            if (inorder[i] == rootVal) {
                inRootIndex = i;
                break;
            }
        }

        int leftSubtreeSize = inRootIndex - inStart;

        root.left = build(preorder, inorder,
                preStart + 1, preStart + leftSubtreeSize,
                inStart, inRootIndex - 1);

        root.right = build(preorder, inorder,
                preStart + leftSubtreeSize + 1, preEnd,
                inRootIndex + 1, inEnd);

        return root;
    }
}
```
