#### [括号生成](https://leetcode.cn/problems/generate-parentheses/)

* 数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

  ```java
  class Solution {
      List<String> list = new ArrayList<>();
  
      public List<String> generateParenthesis(int n) {
          // 思路：相当于有个限制条件，左括号必须大于右括号
          // 传入一个数量
          backtracking(n, 0, 0, new StringBuilder());
          return list;
      }
  
      public void backtracking(int n, int left, int right, StringBuilder sb) {
          if (sb.length() == 2 * n) {
              list.add(sb.toString());
              return;
          }
  
          // 如果左括号数量小于 n，可以添加左括号
          if (left < n) {
              sb.append("(");
              backtracking(n, left + 1, right, sb);
              sb.deleteCharAt(sb.length() - 1);
          }
  
          // 如果右括号数量小于左括号数量，可以添加右括号
          if (right < left) {
              sb.append(")");
              backtracking(n, left, right + 1, sb);
              sb.deleteCharAt(sb.length() - 1);
          }
      }
  }
  ```
