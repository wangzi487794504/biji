#### [不同路径](https://leetcode.cn/problems/unique-paths/)

* 一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

  机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

  问总共有多少条不同的路径？、
  
* 二维dp问题

  ```java
  class Solution {
      public int uniquePaths(int m, int n) {
          //dp[i][j]=dp[i-1][j]+dp[i][j-1]
          //
          int[][] dp=new int[m][n];
          for (int i = 0; i < dp.length; i++) {
              dp[i][0]=1;
          }
          for (int i = 0; i < dp[0].length; i++) {
              dp[0][i]=1;
          }
          for (int i = 1; i < m; i++) {
              for (int j = 1; j < n; j++) {
                  dp[i][j]=dp[i-1][j]+dp[i][j-1];
              }
          }
          return dp[m-1][n-1];
      }
  }
  ```

* 优化成以为dp

  ```java
  class Solution {
      public int uniquePaths(int m, int n) {
          //dp[i][j]=dp[i-1][j]+dp[i][j-1]
          //
          int[] dp=new int[n];
          for (int i = 0; i < n; i++) {
              dp[i] = 1;
          }
          for (int i = 1; i < m; i++) {
              for (int j = 1; j < n; j++) {
                  dp[j] = dp[j] + dp[j-1];
              }
          }
          return dp[n-1];
      }
  }
  ```
