#### [爬楼梯](https://leetcode.cn/problems/climbing-stairs/)

* 假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

  每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

  ```java
  class Solution {
      public int climbStairs(int n) {
          int[] dp=new int[n+1];
          //初始化
          //递归公式 dp[n]=dp[n-1]+dp[n-2]
          dp[0]=1;
          dp[1]=1;
          for (int i = 2; i <= n; i++) {
              dp[i]=dp[i-1]+dp[i-2];
          }
          return dp[n];
      }
  }
  ```
