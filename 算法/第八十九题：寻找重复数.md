#### [寻找重复数](https://leetcode.cn/problems/find-the-duplicate-number/)

* 给定一个包含 `n + 1` 个整数的数组 `nums` ，其数字都在 `[1, n]` 范围内（包括 `1` 和 `n`），可知至少存在一个重复的整数。

  假设 `nums` 只有 **一个重复的整数** ，返回 **这个重复的数** 。

  你设计的解决方案必须 **不修改** 数组 `nums` 且只用常量级 `O(1)` 的额外空间。
  
  ```java
      public int findDuplicate(int[] nums) {
          //使用快慢指针结合数组下表和数组元素构成循环链表
          //变成单向链表有环的问题了
          //如果指针相遇了，说明存在环
          int slow=0;
          int fast=0;
          while (true){
              fast=nums[nums[fast]];
              slow=nums[slow];
              //相遇
              if (slow==fast){
                  break;
              }
          }
          //从头开始
          int index=0;
          while (index!=slow){
              index=nums[index];
              slow=nums[slow];
          }
          return index;
      }
  ```
  
  * 思路二：使用二分法,二分1-N,统计数组中值在这个区间出现的次数，如果大于这个区间数，就可以说明结果在这个区间，接着二分
