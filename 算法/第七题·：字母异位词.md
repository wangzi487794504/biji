#### 字母异位词

* 给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 异位词的子串，返回这些子串的起始索引。不考虑答案输出的顺序。

  *  思路一：超时了。使用hashmap存储模板字符串。再使用双指针，每一次包含就判空

    ```java
    public class Day1 {
        public static void main(String[] args) {
              Day1 day1=new Day1();
            List<Integer> list = day1.findAnagrams("abab", "ab");
            System.out.println(list);
        }
        public List<Integer> findAnagrams(String s, String p) {
            // 定义一个hashmap
            HashMap<Character,Integer> hashMap=new HashMap<>();
            List<Integer> list=new ArrayList<>();
            //做一个剪枝处理
            if (s.length()<p.length()){
                return list;
            }
            //计算字符转的长度，用hashmap做匹配
            for (int i = 0; i < p.length(); i++) {
                hashMap.put(p.charAt(i),hashMap.getOrDefault(p.charAt(i),0)+1);
            }
            HashMap<Character,Integer> hashMap2=new HashMap<>(hashMap);
            //定义左右指针,i是左指针
            for (int i = 0; i < s.length(); i++) {
                int right=i;
                while (hashMap.containsKey(s.charAt(right))){
                    // 没一次都要检查是否满足条件
                    hashMap.put(s.charAt(right),hashMap.get(s.charAt(right))-1);
                    // 如果满足条件，就添加到list中
                    if (isZero(hashMap)){
                        list.add(i);
                        //退出这个循环
                        break;
                    }
                    //检查是否越界
                    if (right==s.length()-1){
                        break;
                    }
                    right++;
                }
                hashMap.clear();
                hashMap.putAll(hashMap2);
            }
            return list;
        }
        //判空处理
        public static boolean isZero(HashMap<Character,Integer> hashMap){
            boolean flag=true;
            for (Map.Entry<Character, Integer> entry : hashMap.entrySet()) {
                if (entry.getValue()!=0){
                    flag=false;
                }
            }
            return flag;
        }
    }
    ```

    

  * 思路二：适用于所有定长滑窗题目。

    ```java
        public List<Integer> findAnagrams(String s, String p) {
            //先定义一个List
            List<Integer> list=new ArrayList<>();
            //统计模板字符出现的个数
            int[] countP=new int[26];
            int[] countS=new int[26];
            
            for (int i = 0; i < p.length(); i++) {
                countP[p.charAt(i)-'a']++;
            }
            //定义左右指针
            for (int right = 0; right < s.length(); right++) {
                //固定窗口思路
                //右端窗口字母先进入窗口
                countS[s.charAt(right)-'a']++;
                //固定窗口，窗口长度是固定的
                int left=right-p.length()+1;
                //left<0说明窗口不够长，让右边窗口向右移动，使得空间到p.length
                if (left<0){
                    continue;
                }
                //长度够了
                if (Arrays.equals(countP,countS)){
                    list.add(left);
                }
                //左端窗口字母离开窗口
                countS[s.charAt(left)-'a']--;
            }
            return list;
        }
    ```

  * 思路三：可变窗口
  
    ```java
        public List<Integer> findAnagrams3(String s, String p){
            //先定义一个List
            List<Integer> list=new ArrayList<>();
            //统计模板字符出现的个数
            int[] countP=new int[26];
            //遍历数量
            for (int i = 0; i < p.length(); i++) {
                countP[p.charAt(i)-'a']++;
            }
            //可变窗口
            int left=0;
            for (int right = 0; right < s.length(); right++) {
                int c=s.charAt(right)-'a';
                //右端字母进入窗口
                countP[c]--;
                //如果字母太多
                while (countP[c]<0){
                    //左端字母离开窗口
                    int d=s.charAt(left)-'a';
                    countP[d]++;
                    left++;
                }
                //如果窗口的长度是p的长度
                if (right-left+1==p.length()){
                    list.add(left);
                }
            }
            return list;
        }
    ```
