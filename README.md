# Java 核心技术笔记库 🚀
## 📚 仓库介绍
* 本仓库系统化整理Java核心技术要点，涵盖**JVM底层原理**、**高并发编程**、**分布式系统设计**等核心领域。内容经过企业级项目验证，本仓库是个人在技术学习过程中的笔记汇总，涵盖多种技术领域的知识，旨在记录学习历程、分享技术见解，也便于自己日后复习回顾。
## 如何使用
* 你可以通过浏览对应的文件夹，查看详细的笔记内容，也可以使用typora打开，部分内容是用onenote做的。如果有任何疑问、建议或者想要进一步交流的技术点，欢迎通过 GitHub 的 Issue 功能与我联系。
## 贡献
* 虽然目前这是个人的学习笔记仓库，但如果你发现了内容错误、想要补充知识点或者有更好的结构建议，也非常欢迎提交 Pull Request，共同完善这份技术笔记。
* 希望这些笔记能对你的技术学习有所帮助，也祝愿我们在技术的道路上共同进步！
